# 每日待办（DailyTodo）

本地使用的待办清单 + 桌面小组件，数据只存在平板本地，无网络权限、无第三方依赖。

## 功能

- **每日任务**：每天 0 点自动重置完成状态和完成情况，前一天的结果自动存进「历史记录」
- **待办**：一次性任务，勾完后第二天自动归档到历史
- **子任务**：每个大任务点「＋子任务」添加；子任务全部勾完，大任务自动完成；勾大任务会把子任务一起勾上
- **完成情况**：点任务名或子任务名，在「完成情况」里随便写（读到第几章、跑了几公里、进度 60%…）
- **桌面小组件**：显示今天所有任务、子任务和完成情况；点某一行直接勾选/取消；点顶部日期打开 App

## 打包 APK（两种方式选一个）

### 方式 A：Android Studio

1. 解压，用 Android Studio 打开 `DailyTodo` 文件夹，等 Gradle 同步完成（如果提示升级 AGP，可以忽略或直接接受）
2. 菜单 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
3. 生成的文件在 `app/build/outputs/apk/debug/app-debug.apk`

### 方式 B：GitHub Actions（电脑不用装 Android 环境）

1. 在 GitHub 新建一个私有仓库，把整个文件夹推上去
2. 打开仓库的 **Actions** 页，「Build APK」会自动跑（约 3–5 分钟）
3. 跑完点进去，在页面底部 **Artifacts** 下载 `DailyTodo-apk`，解压得到 apk

## 装到小米平板

1. 把 apk 传到平板（微信文件传输助手、数据线、网盘都行），点开安装，按提示允许「安装未知来源应用」
2. 添加小组件：桌面空白处双指捏合或长按 → **添加小组件** → 找「每日待办」（HyperOS 里第三方小组件有时在「安卓小部件」分组里）→ 拖到桌面，可以拉伸大小
3. 为了让 0 点重置在桌面上也准时刷新，建议：设置 → 应用设置 → 应用管理 → 每日待办 → **省电策略选「无限制」**，并打开 **自启动**
   （即使不设，打开 App 或点一下小组件时也会自动完成跨天重置，只是桌面显示可能晚一点刷新）
